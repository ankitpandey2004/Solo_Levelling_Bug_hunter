Reads your bug bounty mail with Gmail's read-only API and turns platform replies into dashboard updates — triaged, resolved, duplicate, informative, and bounty amounts. Nothing is sent, deleted, or modified in your mailbox.
Setup: Google Cloud Console → enable Gmail API → OAuth consent screen → add your three addresses as test users → reuse the same client ID as Drive below. Scan one account at a time; use Switch account for the others.

Notifications

Telegram and Discord accept requests straight from this page, so they work with no server. Email needs a relay — point the generic webhook at a Zapier / Make / IFTTT hook set to send you mail.

Private Note Encryption

Firebase Cloud Sync

Create a Firebase project, enable Realtime Database, then paste the web config below.
Comma separated. Applies to both password and Google sign-in. Leave empty to allow any account in your Firebase project.
In the Firebase console enable Authentication → Email/Password, then set Realtime Database rules to:
{ "rules": { "users": { "$uid": { ".read": "$uid === auth.uid", ".write": "$uid === auth.uid" } } } }
That keeps your reports private to your own account.
